These below steps for gcc version < 8.0.0, your system might already have latest version, see next heading
Go to this site : 
https://releases.linaro.org/components/toolchain/binaries/7.5-2019.12/aarch64-linux-gnu/

Download:
gcc-linaro-7.5.0-2019.12-x86_64_aarch64-linux-gnu.tar.xz

Extract using : tar -xvf gcc-linaro-7.5.0-2019.12-x86_64_aarch64-linux-gnu.tar.tar

Export the path: 
export PATH=/home/takeoff/code/gcc-linaro-7.5.0-2019.12-x86_64_aarch64-linux-gnu/bin:$PATH

takeoff@takeoff-ASUS-TUF-Gaming-F15-FX506LH-FX566LH:~/code/Rspi_linux$ export PATH=/home/takeoff/code/gcc-linaro-7.5.0-2019.12-x86_64_aarch64-linux-gnu/bin:$PATH
takeoff@takeoff-ASUS-TUF-Gaming-F15-FX506LH-FX566LH:~/code/Rspi_linux$ which aarch64-linux-gnu-gcc
/home/takeoff/code/gcc-linaro-7.5.0-2019.12-x86_64_aarch64-linux-gnu/bin/aarch64-linux-gnu-gcc

NOTE: The export command needs to done everytime you are proceeding to cross compile.

To export it permanently add the export command to bashrc file.
echo 'export PATH=/home/takeoff/code/gcc-linaro-7.5.0-2019.12-x86_64_aarch64-linux-gnu/bin:$PATH' >> ~/.bashrc
eg:
takeoff@takeoff-ASUS-TUF-Gaming-F15-FX506LH-FX566LH:~/code/Rspi_linux$ echo 'export PATH=/home/takeoff/code/\
gcc-linaro-7.5.0-2019.12-x86_64_aarch64-linux-gnu/bin:$PATH' >> ~/.bashrc
